## v0.9.8 — 2026-09-10

### 수정 사항

- **Claude 비용 과대 계상 교정**: 공식 단가표와 대조해 2건을 바로잡았습니다. 토큰 수는 그대로이고 비용만 내려갑니다.
  - **Claude Sonnet 5** — 단가표에 키가 없어 이전 세대 단가($3/$15)로 계산됐습니다. 공식 단가 $2/$10 적용. 사용 패턴과 무관하게 **−33.3%**.
  - **Claude Fable 5.1** — 캐시 읽기 단가가 $1.00/MTok 으로 계산됐습니다. 공식 $0.25/MTok(0.025배) 적용. 캐시 읽기 비중 95% 계정 실측 **−34.7%**. 캐시 비중이 낮을수록 감소폭이 작습니다.
  - Opus 5 / Opus 4.8 / Fable 5 / Haiku 4.5 는 공식 단가와 일치해 변동 없음. Mythos 5.1 / 5 단가를 추가했습니다.
- **기존 기록 자동 소급**: 업데이트 후 첫 실행에서 로컬 DB 전체를 현재 단가로 재계산하고, 다음 동기화에서 서버 집계(리더보드)를 갱신합니다. 단가표가 바뀐 첫 실행에만 동작합니다 (5만 건 기준 0.2초).
- 교정 후 계산식은 Claude Code `/usage` 의 Session 비용과 같은 리스트 단가 기준입니다. `/usage` 는 현재 세션 1개, 앱은 일자별 전체 세션 누적이라 비교는 같은 세션 기준으로 봐야 합니다.

### 제거

- **Pi 세션 수집 제거**: 사용자가 없어 `~/.pi/agent/sessions` 감시와 Pi 파서를 걷어냈습니다. 이미 수집된 기록은 로컬 DB 에 남습니다.

### 검증

- Rust 78개 테스트 통과, clippy 경고 없음.
- 실제 DB 사본(49,773행)에서 재계산·워터마크 리셋·반복 실행 멱등성 확인.

단가 기준: https://platform.claude.com/docs/en/about-claude/pricing

## v0.9.7 — 2026-09-06

### 수정 사항

- **GPT-6 Astra 비용 누락 수정**: 토큰은 수집됐지만 비용이 0달러로 표시되던 문제를 수정했습니다.
- **기존 기록 자동 복구**: 업데이트 후 앱을 다시 실행하면 저장된 Astra 사용량의 비용을 재계산하고, 동기화 설정에 따라 서버 집계도 갱신합니다. 토큰 수는 유지됩니다.
- **긴 입력 요율 반영**: 요청 입력이 캐시를 포함해 272K 토큰을 초과하면 OpenAI 공식 Standard 요율을 적용합니다. 표시 비용은 API 환산 비용입니다.

변경 내역: https://github.com/madup-dct/madup-token-monitor/pull/7
단가 기준: https://developers.openai.com/api/docs/models/gpt-6-astra
